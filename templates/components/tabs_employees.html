OpsTracking Quick Start

Follow these steps to configure the platform for the very first time.

  1. Define Work Types

    Open the Work Types tab and add Work Type you plan to add.

  2. Create Client Codes

    Switch to the Client Codes tab and add client codes.

  3. Configure Projects

    Move to the Projects tab, add a project name/ID.

  4. Onboard Employees

    Return to the Employees tab and click Add Employee.
